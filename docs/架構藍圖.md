# 架構藍圖

> 整個程式的高層架構與定案。決策由 `domain-modeling` skill 維護（格式見該 skill）。

## 技術棧
前端 Vue 3 (script setup) + TypeScript + Pinia + Vite；桌面殼 Tauri 2；後端 Rust（程序管理、Job Object、log 寫檔、設定檔、開機自啟）。UI 視覺規範＝`minimalist-ui` skill。

## 控制模型
- Rust 端持有所有 bot 的 supervisor：每隻 bot 一個狀態機（Stopped / Starting / Running / Backoff / Stopping），子程序 stdout/stderr 以事件推給前端並同步寫檔。
- 前端只做顯示與下指令（start/stop/restart/edit/remove/import/autostart toggle），不保存任何權威狀態；權威狀態全在 Rust。
- 設定檔 `%APPDATA%\KZ Bot Host\config.json` 由 Rust 讀寫（明文）。
- 系統匣與視窗生命週期由 Tauri 管：X＝hide、匣右鍵 顯示／結束。

## 專案結構
模組歸屬的唯一來源＝ docs/規範.md 歸屬總表；此處只畫高層：
```
src-tauri/src/   Rust：supervisor / process / config / logs / tray / autostart / commands
src/             Vue：bot 清單 + 選中 bot 的側欄（log、操作）
README.md        使用者文件＋bot.toml 規格＋AI 接入教學
```

## 決策

> `決策(日期)` 為穩定 ID，發佈後不重編號；被取代時新增一條指向新 ID、舊條目保留。

### 決策(2026-08-21)：純管家、只跑 exe
管家不自己當 bot，也不內建 Python／uv。要進來的 bot 自行成為可執行檔（建議 Rust 單一 exe，Xense-Bot-rs 為範本）。理由：對方電腦零依賴、管家最單純。

### 決策(2026-08-21)：bot 定義＝通用（exe＋args＋cwd＋env）
以 `bot.toml` 匯入資料夾為主要入口、手動填表為備援；秘密值由使用者在管家補填、存 config.json。

### 決策(2026-08-21)：crash 自動重啟，指數退避
3s 起倍增、上限 5 分鐘；穩定跑滿 60s 歸零。使用者手動停止不重啟。

### 決策(2026-08-21)：子程序掛 Job Object（kill-on-close）
管家結束或被殺，bot 一律跟著死，不留孤兒；右鍵「結束」不跳確認。

### 決策(2026-08-21)：開機自啟＝HKCU Run 鍵、靜默起在匣
自啟時帶 --minimized 不顯示視窗；每隻 bot 各自有「隨管家啟動」開關。

### 決策(2026-08-21)：設定檔明文
`%APPDATA%\KZ Bot Host\config.json` 含秘密值明文（使用者選擇，換機可直接複製）。

### 決策(2026-08-21)：UI 預設極簡、點選才展開 log
主畫面只有 bot 清單（名稱／狀態／開關）；點某隻在右側展開 log 與操作。視覺套 `minimalist-ui`。

### 決策(2026-08-21)：Log 同時進 UI 與檔案
UI 保留最近 N 行；檔案 `%APPDATA%\KZ Bot Host\logs\<bot>.log` 依大小輪替。
