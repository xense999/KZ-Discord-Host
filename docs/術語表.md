# 術語表

> 本專案特有名詞 ↔ 概念，統一用語。由 `domain-modeling` skill 維護（格式見該 skill）。只放定義、不含實作細節。

## Language

**Bot**：
由管家管理的一個外部可執行檔程序（任何語言，只要是 exe），在管家設定中以一筆 BotSpec 描述。
_Avoid_: 機器人（UI 文案可用，文件與程式一律 bot）

**BotSpec**：
一隻 bot 的靜態定義：id、name、exe、args、cwd、env（含 secret 標記）、autostart。
_Avoid_: profile、config entry

**bot.toml**：
放在 bot 資料夾根的宣告檔，讓管家「匯入資料夾」一鍵建出 BotSpec；秘密值不寫在裡面，只宣告需要哪些。
_Avoid_: manifest（口語可用，檔名一律 bot.toml）

**Supervisor**：
Rust 端負責拉起／監看／重啟所有 bot 子程序的元件；權威狀態的唯一持有者。
_Avoid_: manager、daemon

**Backoff**：
bot 非預期結束後到下次自動重啟之間的等待狀態；等待時間指數成長、有上限、穩定後歸零。
_Avoid_: cooldown

**Autostart（管家）**：
開機時由 HKCU Run 鍵啟動管家本身（帶 `--minimized`）。

**Autostart（bot）**：
BotSpec 上的開關：管家啟動時是否自動拉起這隻 bot。

**Job Object**：
Windows 核心物件；管家把所有子程序掛進去並設 kill-on-close，管家消失子程序一律被終止。
