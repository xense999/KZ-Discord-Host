# 現況

> 唯一真實來源。每次有進度就更新這份。

## 專案一句話
KZ Bot Host：Windows 系統匣常駐的 Discord bot 管家（Tauri 2 + Vue 3 + Pinia + Rust），位置 `Desktop\Claude\kz-bot-host`。只跑 exe 型 bot。

## 怎麼跑 / 停
```
npm install
npm run tauri dev        # 開發
npm run tauri build      # 打包（僅使用者說「打包」時）
cd src-tauri; cargo test  # 後端測試
```
停止：系統匣右鍵 → 結束（所有 bot 子程序跟著收掉）。

## 目前可運作的（end-to-end，2026-08-21 本機 dev 模式實測）
- 設定檔載入／autostart bot 自動拉起／子程序無視窗＋Job Object／stdout、stderr 逐行進 UI 與 log 檔／crash 指數退避重啟（3·2^n s，實測第 4 次 24 s、第 6 次 96 s）／停止不重啟／UI 清單＋點選展開面板＋log 串流／設定頁／新增表單／自訂標題列／主視窗固定 480×640、選 bot 往右展開 960×640／新增·編輯·匯入走「bot 設定」視窗、設定走「設定」視窗（皆 520×660／440×480 固定大小）／預設暗色＋透明圓角外框（設定頁可切淺色）。
- Rust 測試 19 綠（config／bot_toml／logs／process／supervisor）；`vue-tsc` 乾淨。
- Job Object 殺管家連帶殺子程序：單元測試驗過（drop Job → 30 s ping 立即結束）；工作管理員實機殺管家尚未手動驗。

## 已知問題 / 技術債
- 用程式模擬點擊驗證 UI 時，若有全螢幕遊戲在前景，`SetForegroundWindow` 會被系統擋下、截圖也會拍到遊戲畫面；驗證要用 `PrintWindow` 抓視窗內容（見 session 筆記）。
- code-review（08-21）已修：stop 逾時可重疊啟動、缺 Stopping 態、前端先 refresh 後 listen 漏事件、autostart bot 歷史 log 跳過、selectBot 判斷、revealed 索引錯位、空 secret 蓋父環境、commands 含驗證、grip 漸層、hide_main 孤兒、shutdown 重複。
- 無邊框視窗只有右下角 grip 可縮放（Windows 無原生 resize 邊框）。
- 停止＝TerminateProcess，不送 Ctrl+C（spec Out of Scope）。
- bot 以 exit code 0 結束也會被當成非預期結束而重啟（bot 本來就該常駐；如要「跑完即停」的一次性程式不適合掛這裡）。
