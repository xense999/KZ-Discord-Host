# KZ Bot Host — 設計共識（2026-08-21 訪談定案）

## 一、兩個獨立專案

| 專案 | 位置 | 技術 | 角色 |
|---|---|---|---|
| KZ Bot Host（管家） | `Desktop\kz-bot-host` | Tauri 2 + Vue 3 + Pinia + Rust | 啟動／監看／重啟多隻 bot exe，系統匣常駐 |
| Xense Bot（Rust 版） | `Desktop\Xense-Bot-rs`（新資料夾） | Rust + serenity/poise，單一 exe | 舊 Python bot 的改寫；同時是 README 教別人「合格 bot 長這樣」的範例 |

舊的 `Xense-Bot-main` 完全不動。

## 二、管家（KZ Bot Host）

1. **定位**：純管家，不自己當 bot。**只跑 exe**（任何語言只要能產生可執行檔），不內建 Python / uv。
2. **bot 定義（通用）**：名稱、執行檔路徑、參數、工作目錄、環境變數（可標記秘密 → UI 遮罩）、「隨管家啟動」開關。
3. **載入方式**：
   - bot 資料夾放 `bot.toml`（名稱、說明、exe 相對路徑、參數、需要哪些環境變數＋哪些是秘密）→ 管家「匯入資料夾」→ 只需補填秘密值。
   - 手動填表也保留。
4. **重啟策略**：crash 自動重啟，指數退避 3s → 6s → 12s … 上限 5 分鐘；穩定跑滿 1 分鐘歸零。使用者手動「停止」則不重啟。
5. **Log**：每隻 bot 的 stdout/stderr 即時進 UI（保留最近幾百行）＋寫檔 `%APPDATA%\KZ Bot Host\logs\<bot>.log`（大小輪替）。
6. **UI 預設極簡**：只列 bot 清單（名稱＋狀態燈＋開關）；**點某隻才在旁邊展開它的 log 與操作**（啟動／停止／重啟／編輯／移除）。
7. **開機自啟**：UI 有總開關（寫 HKCU Run 鍵，免管理員）。自啟時管家**靜默起在系統匣不跳視窗**；有勾「隨管家啟動」的 bot 自動拉起。
8. **關閉行為**：視窗 X ＝ 藏到系統匣；系統匣右鍵「顯示／結束」，雙擊圖示顯示。
9. **結束行為**：所有 bot 子程序掛在 Windows **Job Object**（kill-on-close）下：管家結束或被殺，bot 一律跟著收掉，不留孤兒。右鍵「結束」直接退不跳確認。
10. **設定檔**：`%APPDATA%\KZ Bot Host\config.json`，**明文**（含秘密值）。
11. **單一實例**：第二次開只把既有視窗叫出來。
12. **UI 風格**：套 `minimalist-ui` skill（暖色單色調、字體層次、留白、無漸層無重陰影）。
13. **README**：含一段可直接複製給 AI 的「把你的 bot 接進 KZ Bot Host」教學：產生 `bot.toml`、token 改讀環境變數、前景執行不背景化、建議改寫成 Rust 單一 exe（附 Xense-Bot-rs 當範本）或自行打包成 exe。

## 三、Xense Bot（Rust 版）改寫範圍

搬四個指令，行為與輸出格式一比一照抄：
- `/氰化物領取`、`/銀鉀銀板領取`、`/鈀金領取`：Modal（G/H/D 三棟各一欄、「數量 數量」解析、全形逗號容錯）→ 固定格式 code block。
- `/machine_report`：Modal（Machine 必填／Material 選填／Message 多行必填）→ `- 機台 ｜ 材料` ＋ code block，附 ❌ 刪除鈕（發送者本人或有 manage_messages 權限才可刪）；依機台號碼轉發到 `a-N` 頻道、兩則訊息雙向連動刪除；5 分鐘後按鈕自動移除。

**不搬**：`/task board`（Render 專用）、Flask（保活）、Firebase（無邏輯使用）。
結果＝只吃 `DISCORD_TOKEN` 環境變數的單一 exe，附 `bot.toml`。指令註冊維持全域 sync。

## 四、建議動工順序

2. kz-bot-host 管家。
3. 兩邊 README；打包時走 `release-profile` skill。

## 五、已知風險／待實機
- 二段式：管家被工作管理員「結束處理程序樹」時 Job Object 仍保證子程序收掉；但若管家是被強制斷電則無從保證（本來就無法）。
- serenity Modal 行為（ephemeral、timeout 編輯）需實機對 Discord 驗證格式是否與 Python 版完全一致。
